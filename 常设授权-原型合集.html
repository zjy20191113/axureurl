页面 PRD · 开发说明

资金调拨审核

1. 功能说明

本页仅说明新增常设授权在 APP 资金调拨申请中的入口、共签和免审影响。原资金调拨表单及签署流程继续沿用。

2. 页面规则

  1. 共签可选：未建立授权且为标准账户转入衍生品账户时，显示默认未勾选的“同时签署常设授权协议”；客户勾选后还需勾选“我已阅读并同意上述条款”，一次签名才覆盖两份文件，提交成功后本笔与授权分别待审核。
  2. 已签协议：共签提交成功后，生成带客户签名的《资金划转常设授权书》协议快照，并写入客户签名图片、客户姓名、衍生品账户编号、衍生品账户名称和提交时间；后台可通过协议查看入口读取，业务上默认协议真实有效，不新增真实性或签名核验步骤。
  3. 适用范围：授权覆盖所有支持划转的币种，但仅适用于同币种正向调拨；反向、待审核、驳回或失效场景继续逐笔签署。
  4. 有效授权：显示“本笔使用常设授权”，隐藏逐笔签名和资金调拨协议查看入口，保留授权书查看；提交前展示免签免审及处理时段。
  5. 有效期：自审核通过日期起算一年；到期日精确到日，展示为 YYYY-MM-DD；尚未审核通过时显示“-”。
  6. 状态提示：待审核提示暂不适用免签免审；已生效才进入免签免审；授权状态不改写调拨申请状态。
  7. 处理时段：交易日 09:00–16:00 自动发起处理，其他时段顺延至下一交易日；不以提交成功表示已到账。

3. 字段与操作

字段 / 操作展示与规则
常设授权勾选仅正向且未建立授权时展示，默认未勾选；已建立、反向或不可用授权不展示重复申请入口。
重要提示与同意勾选同时签署常设授权协议后展示中文重要提示及“我已阅读并同意上述条款”复选框；未勾选该确认时不得完成覆盖两份协议的签署。
协议内签署资料共签提交成功后，将客户签名图片、客户姓名、衍生品账户编号、衍生品账户名称和提交时间写入常设授权协议快照；后台通过协议查看入口读取，不重复录入。
查看协议跳转到独立的 PDF 预览页面，展示《资金调拨协议》；返回时保留申请表单、授权勾选及签署状态。
查看授权书跳转到独立的 PDF 预览页面，展示《资金划转常设授权书》；返回时保留申请表单、授权勾选及签署状态。
签名范围未勾选仅覆盖《资金调拨协议》；勾选后同时覆盖两份文件。签署后修改方向、币种、金额或共签选项需重新签署。
授权状态提示待审核显示“常设授权审核中”；已生效显示“本笔使用常设授权”；驳回或失效恢复逐笔签署。
免审确认最终提交前展示方向、币种、免签免审和处理时段；确认时重新校验授权资格。
记录关联共签首笔关联两份文件；免审申请仅引用使用的授权，不生成本笔新签署文件。

待确认：交易日历和资金处理结果。

PDF 交付：两份协议 PDF 由产品负责人线下提供给开发；本原型仅保留查看入口，不实现页面跳转或 PDF 预览交互。

演示边界：原资金调拨字段和签名姓名为示例；真实签名及资金处理未接入。

1. 功能说明

本页仅说明常设授权对资金调拨审核的新增展示和审核联动。原调拨审核状态机继续沿用，自动免审通过另以独立审核方式标识。

2. 页面规则

  1. 授权关联：共签首笔展示资金调拨协议、资金划转常设授权书和同一签名关联；常设授权协议内包含客户签名图片、姓名、衍生品账户编号、衍生品账户名称和提交时间，审核人员可通过协议查看入口读取；无关联订单明确显示未关联。
  2. 同时审核：仅本笔和关联授权均待审核时显示默认未勾选的“同时审核常设授权”；通过时说明授权通过并生效，驳回时说明授权不生效，且两种结果均说明本笔调拨按自身审核结果处理。
  3. 独立审核：常设授权管理可单独审核授权；本笔驳回不联动驳回授权，授权审核不改变调拨申请状态。
  4. 审核方式：自动免审不是新状态，列表新增审核方式列和筛选项；自动免审详情只读，不提供人工审核按钮。
  5. 保留原列表：沿用参考页面的八项筛选及原有列表字段，申请状态默认全部；仅增加独立审核方式和关联常设授权信息，来源继续表示申请发起渠道。
  6. 重复审核阻断：若常设授权已单独审核为已生效、已驳回或已失效，不得再次同时审核；旧页面提交时也必须提示“常设授权已完成单独审核，不能重复审核”并阻断操作。

3. 字段与操作

字段 / 操作展示与规则
原有筛选申请编号、客户中英文姓名、转出账户、转入账户、币种、申请状态、申请时间范围、来源；点击查询应用条件，重置恢复全部，收起筛选保留条件。
申请状态既有状态不变；按参考页面展示待审核、审核通过、审核驳回，不新增自动免审状态。
审核方式独立筛选：全部 / 人工审核 / 自动免审；列表中自动免审申请仍显示审核通过。
原有列表序号、申请编号、客户中英文姓名、转出账户、转入账户、调拨金额、申请时间、审核时间、来源、状态、详情入口；金额显示四位小数及后置币种。
新增列表信息状态之后展示审核方式、常设授权编号及状态，操作列仍在最后；授权编号进入授权详情，未关联显示“未关联”。
来源 / 审核时间来源表示申请发起渠道，与是否免审独立；自动免审显示自动通过时间，无本笔人工审核人。
签署协议共签订单分列两份带客户签名的文件；常设授权书包含本次共签生成的客户签名图片、姓名、衍生品账户编号、衍生品账户名称和提交时间，业务上默认真实有效，不新增真实性或签名核验步骤。
同时审核授权仅两项均待审时出现，默认不勾；通过/驳回时明确说明授权结果及对后续调拨的影响，并分别记录本笔与授权结论。
重复审核阻断授权已单独审核后隐藏或禁用同时审核选项；提交时再次校验，状态非待审核则提示并阻断，不覆盖原授权结论。
自动免审详情展示审核方式、有效授权编号、适用账户和处理说明；不展示人工审核人或审核按钮。

待确认：资金处理结果映射。

演示边界：列表、筛选、审核联动和文件关联为本地示例；新增申请打开已有参考页面，导出仅含当前查询的演示数据。真实已签文件和资金结果未接入。

1. 功能说明

本页用于管理常设授权台账、审核 APP 共签授权，并支持后台录入客户已签署的常设授权。资金调拨原有管理能力不在本页范围内。

2. 页面规则

  1. 适用范围：标准账户至衍生品账户、所有支持划转币种、同币种；有效期为审核通过日期起算一年，到期日精确到日。
  2. APP 已签协议：共签提交后，后台展示带客户签名的《资金划转常设授权书》；协议内包含客户签名图片、姓名、衍生品账户编号、衍生品账户名称和提交时间，业务上默认真实有效，不新增真实性或签名核验步骤；授权仍需审核通过后生效。
  3. 独立审核：仅待审核授权提供通过 / 驳回；通过后生效，驳回不生效，不改变关联调拨订单状态。
  4. 后台新增：录入客户已签文件并确认核对，成功后自动审核通过、生效，不产生待审核节点和调拨订单。
  5. 减少重复录入：客户身份由账户关系识别；新增弹窗不展示客户编号、客户姓名和签名凭证编号。
  6. 关联订单：授权详情展示关联申请编号、处理方式和状态；无关联时明确显示暂无关联订单。

3. 字段与操作

字段 / 操作展示与规则
查询条件账户 / 授权编号、授权状态、建立方式；状态含全部、待审核、已生效、已驳回、已失效。
台账 / 详情账户、授权编号、状态、建立方式、生效时间 / 到期日、关联订单；详情补签署时间、文件和客户只读信息。
到期日统一展示为 YYYY-MM-DD，不展示时分秒；尚未审核通过时不生成到期日，显示“-”。
两个账户必填，均支持下拉模糊搜索且必须选择候选；必须同一客户。修改标准账户后清除衍生品账户。
签署日期 / 文件签署日期和已签授权文件必填；文件支持 PDF、PNG、JPG/JPEG；有效期不按客户签署日期起算。
操作员 / 核对操作员自动取当前登录用户且只读；必须主动确认已核对客户同意及已签授权书。
新增 / 审核新增成功自动审核通过、生效并刷新台账；待审核授权可通过或驳回，备注最多 200 字且驳回必填。

范围说明：沿用标准账户与衍生品账户的对应关系管理授权；重签、续签不在本次需求范围内。

演示边界：文件仅使用示例名称；真实归档、权限和生效计算未接入。
