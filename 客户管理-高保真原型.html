页面 PRD · 改动点与详细规则

客户列表

改动点

  1. 调整共有信息：补齐备注展示，支持查看全文；五级归属单行平铺，固定保留五个位置，空级次显示“-”，不换行或重新编号；示例均保留五级，一级至四级可为空。
  2. 统一授信金额单位：列表、单个新增/编辑、导入模板与预览统一标注“授信金额（万元）”，不换算原始数值。
  3. 移除客户关系图：取消列表关系图入口及组织结构弹窗，保留五级归属展示与节点筛选。
  4. 补充业务摘要：按询价配置、常规期权、孖展合约排列；询价列名为“加点摘要（大陆|香港）”，两个地区的百分比各自上下对齐；独立展示通道费率与税金，返佣/提成无明细时也显示“0 条”。
  5. 整合业务入口：三个业务按钮进入同一客户配置窗口，并直接选中对应 Tab；仍支持多个客户窗口。
  6. 调整单个配置维护：主配置与全部明细类型同时显示，保存明细时才检查主配置；未配置询价直接展示表单。
  7. 优先宽屏左右布局：常规期权、孖展合约的返佣/提成按渠道与员工分左右列；主配置字段尽量同排，询价按大陆与香港左右排列，窗口较窄时自适应上下展示。
  8. 调整明细入口与人员：每类明细独立新增并固定类型；主配置归属员工、直接对接人改为员工管理下拉多选，导入以“、”分隔多人；明细人员手填，允许同类型同名多条。
  9. 调整群编号来源：常规期权、孖展合约的归属群编号均从系统【聊天群管理】下拉选择，各业务独立保存，允许多个客户复用。
  10. 保留原操作按钮：询价、常规期权、杠杆合约、修改、删除继续常显，沿用现有样式。
  11. 新增名称对比演示：顶部统一切换原名称与建议名称；建议尚待客户确认，只切换显示，不改变计算和数据。

详细规则

客户姓名唯一且可修改；修改后同步替换业务配置及归属上级中的客户姓名。共有信息默认展示备注摘要；点击可查看全文。询价配置、常规期权和孖展合约统一进入同一个客户业务配置窗口，通过三个 Tab 切换；多个客户仍可分别打开并最小化，合同业务群编号独立维护。

归属链路固定以单行展示一级至五级五个位置，每个位置显示级次和完整客户名；无值显示“-”，不换行、不省略或重新编号，空间不足时横向滚动。示例数据的五级归属均有值，一级至四级按案例保留空值；不以示例替代存量级次映射确认。取消客户关系图功能，仍保留一级至五级节点筛选。询价“加点摘要（大陆|香港）”按公司、中间人、行情额外加点逐行显示，两地区数值分别右对齐；两类合同无明细（含主配置未建立）时均显示“返佣/提成 0 条”。导出覆盖当前筛选的全部匹配客户。

操作列沿用现有页面的五个常显按钮与配色：询价、常规期权、杠杆合约、修改、删除，不收进“更多”；前三个按钮打开统一窗口并快速定位对应 Tab。此处“杠杆合约”为旧页面按钮文案，指向孖展合约配置；业务字段及其他页面继续使用已确认的“孖展合约”。

业务配置维护规则

宽窗口中，常规期权和孖展合约的返佣/提成区域按左侧中间人（建议名“渠道”）返佣、右侧员工提成排列，每列保留各明细类型及独立新增入口；编辑表单直接在所属类型内展开。主配置业务归属字段尽量同排，通道费率与税金并排；询价按大陆、香港分左右区域。根据窗口实际宽度响应，窄屏或多客户并排后不足以容纳两列时改为上下排列，完整保留字段和操作。

业务配置合并及字段、校验调整归属于客户业务配置功能；系统通用的窗口打开方式见“全局弹窗交互”。三个业务 Tab 的字段与导入项目一致：常规期权单独维护通道费率和税金，四类明细含姓名、比例、对应返佣/提成规则、说明；孖展合约六类明细含姓名、比例、说明，不设返佣/提成规则。两类合同的群编号均从【聊天群管理】下拉选择，分别回显和保存；主配置归属员工、直接对接人使用员工管理下拉多选，列表、详情、导出以“、”完整展示多人。原型字典为本地示例，正式选项读取对应系统功能；明细姓名全部手填，允许同一类别多条同名记录。

主配置与全部明细分区始终同时展示，分别保存和取消；尚无主配置也可先填写明细，保存明细时才检查主配置，不存在时提示并保留输入，补充保存主配置后可继续保存。每个明细类型旁独立提供新增按钮，表单固定所属类型，不再选择明细类型。询价未配置时直接显示报价分类ID及六项地区加点，保存通过后才建立配置，无新建前置按钮。导入仍按原主配置依赖规则执行；正式询价数值边界仍待确认。

改动点（新增功能）

  1. 新增客户批量导入：提供模板、上传、校验预览、执行及结果查看的完整流程。
  2. 支持新增与更新：以唯一客户名称匹配；不存在时新增，已存在时更新，更新字段留空表示不修改。
  3. 先预览再执行：上传后先预览逐行校验结果，仅执行通过行；失败行订正后重新上传，单次最多 500 条。
  4. 增加归属预解析：根据归属上级展示五级完整链路，与列表样式一致；更新空上级保留已有链路，关系无效时明确提示无法生成。
  5. 错误定位到字段：问题字段标红并在值旁展示原因，覆盖已确认的全部失败原因；文件级失败从原型外层切换演示。
  6. 明确互斥提示：重复姓名、同批次新增客户间的上级引用等互斥记录，后序行提示“与第 X 条互斥”。
  7. 新增页内模板示例：直接展示客户名称、授信金额（万元）、归属上级、备注、状态五列及示例行；归属只填上级，不独立录入五级字段。

详细规则

上传页直接展示客户共有数据模板的五个字段及填写示例，无须先解析文件。示例中的空白保持为空，不用“-”代填；不包含一级至五级独立录入列。模板预览为原型评审辅助，下载和文件解析边界不变。

单次最多 500 条。文件按顺序逐行预览；同文件重复姓名，或后序新增客户引用先序新增客户为上级时，后序行解析失败，原因“与第 X 条互斥”。其他通过行可以执行，失败行修正后重新上传。

新增时空上级代表顶级；更新时空值表示不修改。执行仍须复核校验，不保证预览通过必然执行成功。

预览展示归属上级和五级归属链路（预解析），一级至五级单行平铺、空级次为“-”、完整名称不省略，与列表共用口径。关系无效时对应字段标红并说明原因，链路不伪造；更新空上级保留原链路。授信金额统一使用万元、非负、最多两位小数，不换算已有数值。实际级次映射仍按完整 PRD 待确认项核对。

所有问题字段保留原值，在同一单元格的值旁直接展示原因；同字段多原因、同行多字段分别列明，不只在末列汇总。预置案例覆盖姓名必填与格式、互斥、上级不存在/自指/循环/超层级、授信金额格式/负数/精度、状态与备注；具体名称和备注限制沿用现有系统。外层“导入场景 · 原型演示”可选择文件格式、大小、行数、版本、损坏、缺工作表、表头及空文件案例；文件级失败不能执行。

改动点（新增功能）

  1. 新增业务配置批量导入：提供询价配置、常规期权、孖展合约三种导入类型，均按客户名称绑定已有客户。
  2. 提供合同双表模板：常规期权、孖展合约各分主配置与返佣/提成明细两表；常规期权通道费率、税金独立成列，两类业务群编号独立。
  3. 支持多条明细：常规期权四类、孖展合约六类；姓名、比例、说明分别成列，常规期权另有按类型匹配的返佣/提成规则。人员姓名手填，同类型允许同名多条。
  4. 明确执行单位：主配置按行、明细按“客户＋类型”整组处理；出现的组替换旧组，未出现的组不修改，任一行失败则整组保留旧值。
  5. 提供询价配置模板：报价分类ID匹配系统字典；公司、中间人、行情额外加点各拆为大陆和香港两列，共六项百分比。
  6. 新增页内模板示例：随业务类型展示完整表头与示例行，合同模板可切换两张工作表；字段、类型、规则同步参与新老名称对比。
  7. 字段旁显示完整错误：主配置与明细均展示全部字段，问题值标红并附原因；同组其他有效行仅说明受哪行影响，整组不执行。覆盖当前已确认的全部失败原因。

详细规则

上传页随业务类型展示对应模板的完整表头及填写示例；合同业务可切换主配置与返佣/提成明细工作表，询价配置单表展示六个独立地区加点列。模板中的字段、明细类型及返佣/提成规则跟随顶部新老名称切换，示例姓名和数值保持不变。字典值为本地示例，不代表系统真实数据；模板预览与解析校验结果分开。

按客户姓名匹配已有客户；常规期权和孖展合约工作簿均分“主配置”和“返佣/提成明细”两表，两表数据行合计不超过 500。主配置重复客户时后序行提示“与第 X 条互斥”。

常规期权有中间人前后端返佣、员工前后端提成四类，明细填写姓名、比例、按明细类型匹配的返佣/提成规则和说明：中间人前端为公司加点、公司加点-交易成本、咨询费、咨询费-交易成本；中间人后端为税金、税金-交易成本；员工前端为公司加点、公司加点-交易成本、咨询费、咨询费-交易成本、咨询费-中间人咨询费返佣、咨询费-交易成本-中间人咨询费返佣、中间人加点剩余部分；员工后端为税金、税金-交易成本。孖展合约主配置仅包含群编号、归属员工和直接对接人；六类明细为中间人认购费、续期费、投资者分成返佣及员工对应三类提成，仅填写姓名、比例、说明，不设返佣/提成规则。比例为 0-100%，最多两位小数，0 有效。所有返佣和提成明细的姓名均为手填文本，不匹配员工数据字典；同一明细类型下允许添加多个相同姓名。

文件中出现的“客户＋明细类型”整组替换，未出现的类别不修改；一行无效则整组失败并保留旧值。主配置成功不受明细组失败影响。已有主配置可只导入明细；没有主配置时提示先建立。普通空白不清空旧值，清空方式待确认；停用群人工核验。

询价配置使用单表，一位客户在同一文件中至多一行，按姓名绑定已有客户。报价分类ID须匹配系统【报价分类】字典；公司、中间人、行情额外加点各拆为大陆和香港两列，单位为%。重复客户后序行互斥，格式或字典校验失败的行不执行；通过行新增或更新配置。加点的上限、精度及新增空值规则待确认，演示ID不代表系统真实字典。

每个具体问题字段保留原值、标红并在值旁显示原因；同行多错误分别定位。主配置预览补齐归属员工和直接对接人；明细组只标红致错字段，同组未致错行说明“本行字段通过；受第 X 行影响，整组不执行”。预置案例覆盖名称、互斥、字典、类型、必填、比例格式/范围/精度、常规期权返佣/提成规则及主配置依赖，询价六个地区加点均有格式错误示例。未确认的询价数值边界不补造规则；文件级失败可从外层演示选择器切换。

多人主配置：常规期权和孖展合约的归属员工、直接对接人单元格支持“姓名甲、姓名乙”；按“、”拆分、去除姓名两端空格后逐个匹配【员工管理】。任一姓名不匹配时，在对应字段旁列出具体姓名，整条主配置不执行，不只保存其中匹配的人员。更新时该单元格整体为空仍表示不修改，非空名单整体替换该字段原名单，不追加合并。

改动点（新增功能）

  1. 新增导入文件中心：提供系统级独立功能，集中汇总各模块导入批次，展示业务类型、原始文件、上传信息、通过/失败数量及最终结果。
  2. 明确文件保留与下载：原始文件长期有效；列表提供“下载导入文件”，对应当前批次上传原件，并保留结果文件和失败行文件下载。
  3. 精简结果查看：移除“查看结果”按钮及逐行结果详情区；列表继续展示通过/失败数量及状态。
  4. 明确重新上传：修正文件生成新批次，以最新批次结果为准；不合并旧结果，也不回滚已成功记录。
  5. 补充评审示例：预置六个导入批次，覆盖全部成功与部分成功，支持筛选及下载入口反馈；真实文件下载仍为未实现能力。

详细规则

系统级汇总各模块导入批次；新产生的原始文件长期保留，不设有效期。重新上传产生新批次，最新批次结果不与旧批次合并，也不回滚旧批次已成功写入的数据。

正式实现需按批次下载原始导入文件、结果文件；有失败行时另提供失败文件下载，保留致错行及原因供订正。原件下载保留原文件名、格式及内容，不用结果文件代替。历史文件只在原件与批次信息可取得时回补；文件不可用时提示并保留记录，下载权限沿用现有控制。

改动点

  1. 明确导出范围：导出当前筛选条件下的全部匹配客户，不按勾选或当前页。
  2. 固定客户总览导出：取消模式选择；总览一行一客户，按所选字段分组联动列和附带明细表。
  3. 补齐返佣/提成明细：附所选合同业务的明细表；逐条导出姓名、比例、说明及适用规则，同名多条和 0 比例完整保留。
  4. 新增页内文件示例：直接展示工作表、完整表头与示例数据，可切换查看；保留完整备注和五级归属。

详细规则

导出当前筛选条件下的全部匹配客户，不按勾选或当前页。总览主表一行一客户，使用共有信息、常规期权、孖展合约和询价配置分组表头；保留返佣/提成条数，并在同一文件中附上选中业务的完整返佣提成明细工作表。

导出页面直接展示客户总览示例文件的表头与数据，不提供模式选择。总览始终保留；勾选常规期权、孖展合约时分别附带对应返佣提成明细表，最多三张工作表，可切换查看。明细一条一行，允许同名，不去重，各表以客户姓名关联；询价配置保留在总览的对应字段组内。

导出字段和数据范围遵守现有权限；备注完整导出，未配置业务明确标注“未配置”。

改动点（全局交互优化）

  1. 统一系统弹窗交互：调整系统各模块的窗口样式、打开方式及层级关系；此处用客户详情演示通用交互。
  2. 减少完整弹窗叠加：查看转编辑在当前窗口切换；轻量内容就地展开，从属操作在窗内分区或子视图承载，独立任务另开工作窗口。
  3. 保留多窗口能力：不同对象可同时打开，支持任务栏切换、最小化、恢复；重复打开相同对象聚焦已有窗口。
  4. 优化查看与操作：宽屏支持并排查看，窄屏单窗切换；窗口标题、返回路径、滚动内容及操作区保持可访问。
  5. 统一未保存保护：最小化或切换窗口保留输入；关闭或离开未保存内容前确认，删除及放弃等短决策使用简短确认弹窗。

详细规则

适用范围为系统全局的弹窗与工作窗口交互，和具体业务字段、字典及校验分开评审。当前以客户详情为本地示例，表达通用打开方式，不代表其他模块已经完成接入。客户三类配置合并、主配置与明细展示、新增入口和人员来源归属于“客户列表”中的业务配置维护规则。

同一对象的查看、编辑在当前窗口内切换，保存成功后恢复查看，取消不保存。轻量补充内容直接展开；与当前任务有关的复杂操作进入窗内分区或子视图，子视图提供返回路径并保留原上下文；独立任务使用独立工作窗口。完整业务表单不继续叠加为子弹窗，删除、放弃等短决策可保留单层确认。

工作窗口采用非模态形式，底层列表仍可操作。相同对象重复打开时聚焦或恢复已有窗口，不重复创建；不同对象分别保留。任务栏显示对象名称、当前任务及未保存或最小化状态。宽屏最多两个窗口并排，其他窗口仍可从任务栏切换；窄屏一次显示一个窗口。

最小化、恢复和切换窗口均保留未保存输入，不等于关闭。关闭窗口或离开当前未保存内容前确认是否放弃；继续编辑时保留输入与原位置。窗口内容超高时允许滚动，标题、关闭及保存/取消等操作保持可访问。刷新、离开模块后的持久化能力不由本地演示保证，正式接入需核对。
